#Task 2 - Exploratory Data Analysis (EDA)

##Dataset
Titanic Dataset

##Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

##Analysis Performed
- Dataset overview
- Summary statistics
- Missing value analysis
- Survival analysis
- Gender distribution
- Passenger class distribution
- Age distribution
- Fare outlier detection
- Correlation heatmap

##Insights
- Most passengers belonged to 3rd class.
- Male passengers were more than female passengers.
- Majority of passengers did not survive.
- Fare contains outliers.
- Average passenger age is around 30 years.
