#Task 5 - Amazon Product Analysis

##Dataset
Amazon Products Dataset

##Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

##Analysis Performed
- Product price distribution
- Product rating distribution
- Best seller analysis
- Price vs Rating analysis
- Missing value analysis

##Key Insights
- Product prices vary across the dataset.
- Most products have ratings between 4 and 5 stars.
- Best seller products were identified.
- Price does not always indicate a higher rating.
